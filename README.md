Entry for the make.fun bounty [One Star, Written in Sap](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4): a single one-line 1-star review from a houseplant about its human owner, under 280 characters.

## The review

> One star. Sold as 'low maintenance.' He hasn't repotted me in two years. The pot is now a suggestion.

(101 characters.)

## How it works

`main.ts` writes the review verbatim to `/output/entry.txt`, validating first that it is 1–279 non-blank characters, then reading the file back to confirm it is byte-identical.

Run locally with:

```sh
node main.ts
```
